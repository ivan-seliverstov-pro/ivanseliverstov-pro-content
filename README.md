# Контент сайта ivanseliverstov.pro

Здесь хранится всё, что видно на сайте: тексты в файле `content.json` и картинки
в папке `images`.

Меняете здесь — через несколько минут меняется на сайте.

## С чего начать

Один раз установите две программы и скачайте эту папку к себе:

1. [Git](https://git-scm.com/downloads) — при установке везде нажимайте «Далее».
2. [VS Code](https://code.visualstudio.com) — редактор, в котором вы будете работать.
3. Откройте VS Code, слева внизу нажмите на значок человечка и войдите через GitHub.
4. Нажмите `Ctrl+Shift+P`, наберите `Git: Clone`, выберите этот репозиторий
   и укажите папку на компьютере, куда его положить.

Дальше вы просто открываете эту папку в VS Code.

## Как поменять текст

1. Откройте файл `content.json`.
2. Нажмите `Ctrl+F` и вставьте кусок текста, который хотите заменить, — редактор
   найдёт его в файле.
3. Замените текст. Менять можно **только то, что стоит в кавычках справа от двоеточия**:

   ```json
   "tagline": "вот эту часть менять можно"
   ```

   Слово слева от двоеточия — название поля, его трогать нельзя.
4. Сохраните файл: `Ctrl+S`.

## Как поменять картинку

1. Перетащите файл мышкой в нужную папку внутри `images`. Лучше в формате `.webp` —
   сайт будет грузиться быстрее.
2. В `content.json` впишите путь к нему. Путь всегда начинается с `/images/`
   и повторяет расположение файла по папкам:

   ```
   файл лежит:    images/projects/moy-proekt.webp
   в файле пишем: "/images/projects/moy-proekt.webp"
   ```

## Как отправить изменения на сайт

1. Нажмите `Ctrl+Shift+G` — появится список изменённых файлов.
2. В поле сверху коротко напишите, что поменяли: например, «обновил описание услуг».
3. Нажмите кнопку **Commit**, а затем **Sync Changes**.
4. Через несколько минут откройте сайт. Если правка не видна — обновите страницу
   через `Ctrl+F5`.

## Как проверить, что ничего не сломалось

VS Code проверяет файл на лету. Если вы случайно удалили кавычку или запятую,
он подчеркнёт это место **красной волнистой линией**, а внизу окна появится
красный кружок с числом ошибок.

Правило простое: **есть красное подчёркивание — не отправляйте**. Нажмите `Ctrl+Z`
столько раз, сколько нужно, чтобы отменить правки, и попробуйте снова.

## Чего делать нельзя

- **Удалять и переименовывать крупные разделы файла** — `siteMetadata`, `heroData`,
  `skillsData`, `clientsData`, `projectsCasesData`, `projectsCategoriesData`,
  `reviewersData`, `gratitudeImagesData`, `questionsData`. На них держится вёрстка сайта.
- **Ставить лишнюю запятую или убирать нужную.** Самая частая ошибка — запятая
  перед закрывающей скобкой.
- **Указывать путь к картинке, которой нет.** Сначала положите файл, потом впишите путь.
- **Переименовывать файл** `content.json` **и папку** `images`.

## Если всё-таки ошиблись

Ничего страшного не случится. Перед публикацией файл проверяется: если в нём ошибка,
обновление просто не применится, а сайт останется работать на прошлой версии.
Исправьте и отправьте ещё раз.

## Важно

Этот репозиторий открыт всем — любой человек в интернете может посмотреть, что здесь
лежит, и удалённые файлы тоже остаются видны в истории. Кладите сюда только то,
что и так будет опубликовано на сайте.
